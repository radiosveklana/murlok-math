# Автотесты

- `bash tools/e2e/run-all.sh` — полная проверка перед выкладкой (нужен `node tools/e2e/serve.js 8765`).
- `node tools/e2e/journey.js` — пользовательский путь «сайт → регистрация → семья → дуэли» на настоящем локальном сервере (сам поднимает API на :3916 с временной папкой данных и статику на :8766; письма с кодами пишутся в файл, клиент ходит в локальный API через localStorage `murlok-api-base` — только на localhost).
