# Академия сыщика — новые предметы

Новые темы встраиваются в «Мурлок и Ко» по той же схеме, что и математика: **учебник → тренажёр → разбор ошибок → игры**, с той же экономикой (конфеты, кристаллы, опыт, задание дня), тем же котиком-маскотом, голосом и детективным сюжетом. Математика не меняется.

## Архитектура

| Файл | Что внутри |
|---|---|
| `academy.js` | движок предметов: хаб «Академия», экран предмета, учебник (карточки), тренажёр (типы вопросов), разбор ошибок (интервальные повторения), поиск, прогресс |
| `content/space.js` | Космос |
| `content/safety.js` | Безопасность |
| `content/teen.js` | Энциклопедия подростка |
| `content/think.js` | Критическое мышление |
| `content/read.js` | Скорочтение (+ особые упражнения) |

**Данные предмета:** `{ id, name, icon, color, intro, units: [{ id, title, icon, cards:[…], quiz:[…] }], games? }`.

**Типы вопросов (общие для всех предметов):**
- `one` — один ответ из нескольких; `tf` — правда/неправда (мифы);
- `order` — расставить по порядку (планеты, шаги действий);
- `case` — ситуация «Что ты сделаешь?» с разбором каждого варианта (безопасность);
- `sort` — разложить по группам (факт/мнение, безопасно/опасно/спроси взрослого);
- `input` — ввести ответ.
У каждого вопроса есть объяснение `why` — показывается после ответа.

**Разбор ошибок:** ошибочные вопросы попадают в коробки Лейтнера (повтор через 0 → 1 → 3 → 7 дней); после 4 верных ответов подряд вопрос считается выученным.

**Прогресс:** `S.acad[предмет] = { read:{урок:true}, best:{урок:звёзды}, box:{вопрос:[коробка, дата]} }`. Облачная копия уже сохраняет всё состояние.

**Награды:** прочитанный урок — 2 🍬, верный ответ — 1 🍬, тренажёр без ошибок — +💎, задание дня засчитывается.

**Голос:** котик читает карточки учебника вслух (серверная озвучка тем же голосом), подсказки маскота — как в математике.

## Предметы и способы освоения

1. **🚀 Космос.** Солнечная система, планеты, Луна, звёзды, космонавты, гравитация, масштабы. Способы: карточки с яркими фактами, «расставь планеты по порядку», мифы и правда, интервальное повторение, экспедиция-миссия.
2. **🛡️ Безопасность.** Интернет (личные данные, пароли, мошенники, незнакомцы в сети), личная безопасность (дома один, улица, огонь, вода), опасный незнакомец, буллинг (что делать жертве и свидетелю), «моё тело — мои правила», хорошие и плохие секреты. Способы: ситуации с выбором и разбором последствий, правила-карточки, «светофор» (безопасно / опасно / спроси взрослого), телефоны помощи (112, детский телефон доверия 8-800-2000-122).
3. **📘 Энциклопедия подростка.** Для девочек и мальчиков: как меняется тело, гигиена, эмоции и настроение, дружба и симпатия, уверенность в себе, сон и еда, интернет и фото. Формат: «Вопросы, которые стесняются задать» — короткие честные ответы, поиск, «Это нормально?». Без подробностей, не подходящих по возрасту; везде совет поговорить с мамой, папой, врачом. Что ребёнок читает в энциклопедии, родителям не показывается — чтобы не было стыдно спрашивать.
4. **🧠 Критическое мышление.** Факт или мнение, причина и следствие, ловушки в рассуждениях, проверка новостей и рекламы, логические задачи, «найди лишнее». Способы: детективные мини-дела, сортировка утверждений, «почему ты так думаешь?».
5. **⚡ Скорочтение.** Таблицы Шульте (поле зрения), вспышки слов, чтение по строке с бегущим указателем, тексты на время с вопросами на понимание, замер слов в минуту и график роста.

## Порядок разработки
1. Движок предметов + Космос (проверка движка) → тесты → выкладка.
2. Безопасность (тип `case`, `sort`) → тесты → выкладка.
3. Энциклопедия подростка (статьи, поиск) → тесты → выкладка.
4. Критическое мышление → тесты → выкладка.
5. Скорочтение (особые упражнения, замер скорости) → тесты → выкладка.

## Правило: не ломать старое
Новые предметы — отдельные файлы и экраны; старый код меняется только в точках подключения (плитка на главной, скрипты в `index.html`, кэш в `sw.js`). Перед каждой выкладкой — `bash tools/e2e/run-all.sh` (полный путь ребёнка в математике, игры, голос, домик, облако, вёрстка на телефонах) плюс новый тест академии.
