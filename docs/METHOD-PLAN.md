## 1. БАГ: «в проверке по окружайке всплывают математические примеры»

### 1.1 Причина (проверено в node и в браузере через puppeteer)

Утечки между предметами нет. Ни `QUIZ_EXTRA`, ни TaskBank, ни Енот не подмешивают в окружайку задачи из `math4`: ключи `QUIZ_EXTRA` разведены по предметам, а `mergeExtra()` (academy.js:9) кладёт вопросы только в свой предмет. **Математику содержит сам контент предмета `world`**: туда намеренно добавлены «межпредметные» текстовые задачи с вводом числа на цифровой клавиатуре.

**A. Генератор «Круговорот воды»** — `content/world.js:827-833` (`wcT[7]`). В 3 из 4 веток получается арифметика:
- стр. ~828 (`k === 0`): «Вода нагрелась до 40 °C. На сколько градусов ей ещё нужно нагреться…» → `100 − t`;
- стр. 829 (`k === 1`): «…на сколько градусов её нужно охладить…» → `t − 0`;
- стр. 830 (`k === 2`): «Из бочки каждый день испаряется 4 л. Сколько за 7 дней?» → `a × d`.

В тренажёре темы с генератором (academy.js:107) **6 из 8 вопросов** берутся из `u.gen` (`genStatic` по умолчанию 2). Значит, такой «пример» попадает примерно в 40% тренировок по теме. Вопросы с вводом числа есть и в других генераторах окружайки: в `russia_nature`, `food_chains` и `minerals` это 10–13% вопросов, ответ — подсчёт с цифровой клавиатуры. Визуально это тоже похоже на математику.

**B. Статические вопросы `world` — 9 текстовых задач:**

| Файл:строка | Задача |
|---|---|
| world.js:105 | 9 + 15 (возраст и котёнок) |
| world.js:202 | 25 × 4 бутылки |
| world.js:251 | 3 × 7 см (подсолнух) |
| world.js:283 | 9 : 3 (гроза) |

Ещё около 20 вопросов с вводом числа требуют точно вспомнить число: 1642, 5642, 1903, 1984, 2021, 750, 190… Для 10 лет это слишком сложно, и выглядит как пример.

**C. Те же задачи всплывают и в других режимах**, которые берут вопросы предмета:
- «Ошибки Енота» → «Окружающий мир»: `modes.js:219` `qFromUnit` берёт `u.gen` в 75% случаев. Вопрос с вводом числа превращается в «Енот: Ответ — 1312!», а исправлять нужно на цифровой клавиатуре;
- «Новое дело» → Академия/выбор тем: `mkAcad` (modes.js:367) берёт любые вопросы из `unitQs`;
- «Разбор ошибок»: сгенерированные задачи сохраняются в `a.gq` и возвращаются.

**D. Сопутствующий дефект в «Новом деле → Выбрать темы»** (modes.js:372-381). Если выбраны только темы окружайки, но они недоступны (урок закрылся, id переименован), то `acadPool` возвращает пустой список. Тогда `nS += nA` → **все 4 улики становятся математикой**. А если пусты оба списка, `ids = null` → 2 задачи из всей математики. Ребёнок выбрал окружайку, а получил примеры.

### 2.2 Сквозные проблемы качества

1. **Вопросы на точное число** (годы, глубины, численность) через ввод: 1642, 5642, 1903, 1984, 1895, 2021, 750, 190, 270, 400. Это механическое запоминание, ФОП его не требует, и такие вопросы похожи на примеры. → Перевести в `one` с правдоподобными вариантами разного порядка или в задание «упорядочь по величине».
2. **Устаревающие числа:** амурские тигры (около 750 по учёту 2022 года), «больше 190 народов» (перепись 2020 даёт 194), около 200 стран (195 признанных в ООН — уточнить формулировку), Красная книга РФ (животные — 2021, растения — 2024). → В карточках добавить «по данным на 2022 год» и указывать год.
3. **Материки:** «6 материков» — верно для российской школы. Нужно следить, чтобы где-то не появилось «7» (англоязычная традиция), и согласовать с «частями света» (6).
4. **Терминология Плешакова:** «производители / потребители / разрушители» — термины учебника, хорошо. Природные зоны в учебнике называются «зона арктических пустынь, тундра, лесная зона (тайга, смешанные и широколиственные леса), зона степей, пустыни, субтропики (Черноморское побережье)». В генераторе нет зоны «смешанные/широколиственные леса» и субтропиков, хотя в `ZORDER` есть «Смешанные леса». → Добавить зону с жителями и «Черноморское побережье Кавказа».
5. **Подсказки в формулировке:** в `case` и `one` правильный вариант часто самый длинный и самый «добрый». Ребёнок научится угадывать по длине. → Правило редактуры: длина вариантов ±20%, неверные варианты правдоподобны.
6. **`tf` занимает 15–40% вопросов**: угадывание с вероятностью 50%. → Для `tf` просить «почему» (см. §4) или засчитывать только пару вопросов «утверждение + исправление».
7. **Повторы между предметами:** гигиена (health / teen / body), клещи (obzh / health / safety), лёд и вода (obzh:water_ice / safety:road_water_ice / obzh:weather_water), 112 (safety / obzh / world:kindness). → Связать перекрёстными ссылками («этот вопрос есть и в ОБЖ»). Дубли засчитывать в обоих предметах, а не показывать дважды.

### 2.5 Космос, Тело, ЗОЖ, ОБЖ, Безопасность — ключевые замечания

- **Космос:** самый проработанный предмет, по глубине выше программы. Риск устаревания: число спутников у планет — Сатурн 274 и Юпитер 97 по данным 2024–2025, цифры меняются → давать «больше 90 / больше 270» с годом. «Плутон — карликовая планета» (с 2006 года). МКС планируют свести с орбиты около 2030 года. Убрать арифметику из `iss_life` и `universe` (§1).
- **Тело:** глубже программы (клетки, витамины). Хорошо для любопытных, но для 4 класса сделать уровни «база / ещё глубже». Перевести вводы чисел (206 костей, пульс) в `one`.
- **ЗОЖ:** нормы сна для 10 лет — 9–12 часов (AASM/ВОЗ), проверить везде. Норма воды через «стаканы» — давать как ориентир, не как обязательство. Задачи про часы (sleep / school_day) перенести в math4 «Время», и это будет хорошая межпредметная связь именно там.
- **ОБЖ:** первая помощь соответствует порядку «безопасность → взрослый → 112». Надо сверить с приказом Минздрава 477н: ожог — 20 минут прохладной воды, без масла и льда; кровь из носа — голову **вперёд**; обморожение — **не растирать снегом**; клещ — снимает взрослый или травмпункт. Шаблон «7 case / 3 order / 2 sort…» одинаков во всех уроках → разнообразить. Не хватает темы **ПДД**: знаки для пешехода, светофор, велосипед (до 14 лет — по тротуару или с детской площадки), СИМ и самокаты, световозвращатели, железная дорога.
- **Безопасность:** сильные ситуационные кейсы. Добавить «мошенничество в играх: скины / донат / „код из СМС“», «дипфейк-голос мамы просит деньги», «геолокация в фото».

### 2.6 Мышление, Скорочтение, Общение, Креативность, Истории, Подросток

- **think:** хороший набор УУД (факт/мнение, источник, ловушки мышления). `patterns` — 15 вводов чисел (числовые закономерности): это математика, её нужно пометить `calcOk` или перенести. Добавить работу с **несплошными текстами** (таблица, расписание, схема) — функциональная грамотность и ВПР.
- **read:** уроки рассказывают *о* чтении, а **читательской практики мало**. Нужны: 30+ текстов по 150–400 слов (научно-популярные и художественные из программы 4 кл.), вопросы трёх уровней по PIRLS/ВПР («найди информацию / сделай вывод / оцени»). Норма техники чтения для конца 4 класса — около 90–120 слов в минуту вслух (ориентир, не стандарт ФГОС). Тезисы «подавить внутреннюю речь» и «фотографическое чтение» для 10 лет научно не подтверждены: смягчить или убрать. Шульте — тренировка внимания, а не чтения, так и подписывать.
- **talk:** качественное социально-эмоциональное обучение (Я-сообщения, компромисс). Ситуации хороши, но правильный вариант очевиден → добавить «серые» варианты (`~`) и «что ты почувствуешь».
- **creative:** у вопросов на креативность **один правильный ответ** — это противоречит сути креативного мышления (PISA CT: беглость, гибкость, оригинальность, проработка). → Открытые задания: «придумай 5 применений» с самооценкой по чек-листу и сохранением в «альбом идей» (creative-games.js уже есть — сделать его центром). Закрытые вопросы оставить только на понятия.
- **stories:** проверять апокрифы и приписанные цитаты: «Эдисон и 10 000 неудач», «Эйнштейн плохо учился» — **миф**, «Гагарин: Поехали!» — верно. Даты рождения, рекорды и даты — по одному источнику.
- **teen 12+:** вне ФОП НОО. Обязателен замок родителей (ПИН), темы тела — только с согласия родителя. Сейчас пометка «12+» есть, но вход открыт.

### 2.7 Математика (Школа) — коротко

Сильные стороны: пошаговое умножение и деление столбиком с вопросами кота на каждом шаге («пишу, запоминаю»), составные уравнения и «метод коробки», «Проверь мою тетрадь» (поиск первой ошибки по шагам) — методически отлично и близко к Моро.

Пробелы против ФОП и ВПР-4:
- задачи **вдогонку** и с отставанием, задачи на нахождение четвёртого пропорционального, задачи в 3–4 действия с краткой записью и схемой;
- **геометрия на клетчатой бумаге** (ВПР №5), построение, пространственное мышление (ВПР №11: развёртки, кубики);
- логика «все / некоторые / ни один» (ВПР №12), календарь, план местности, единицы скорости;
- величины: объём (литр), скорость в м/мин;
- **прикидка** и устный счёт — стратегии («удобные числа»), а не только скорость;
- миллионы и миллиарды (классы в Моро 4).

Отдельно: перенести сюда межпредметные задачи из Академии («Задачи о природе и космосе»), с флагом `calcOk`.

## 4. Ход обучения: как сейчас и как лучше

**Сейчас:** урок-карточки → «Проверь себя» (2 вопроса) → тренажёр из 8 вопросов → звёзды → открывается следующий урок; ошибки → Лейтнер 1/3/7 дней. Решённое верно **исключается навсегда** (academy.js:103 `okm`, «Тема пройдена»).

| Практика | Сейчас | Рекомендация |
|---|---|---|
| Извлечение из памяти (retrieval practice) | есть (тренажёры) | хорошо, но нужно и повторение верных ответов |
| Интервальное повторение (spacing) | только для ошибок | верные ответы в ящики 3/7/21/60 дней; «повторение дня» на главной |
| Чередование тем (interleaving) | «Смешанная» внутри предмета | смесь по предметам и старым темам; в тренажёре 1–2 вопроса из прошлых уроков |
| Разобранные примеры (worked examples) | в математике отлично (столбик по шагам) | в Академии — пример рассуждения в `why` («Почему: …, значит…») |
| Постепенное снятие подсказок (faded guidance) | столбик: подсказки → самостоятельно | то же для задач: краткая запись с пропусками → без пропусков |
| Качество обратной связи | `why` есть везде | писать *почему*, а не повторять ответ; при ошибке — короткая подсказка и вторая попытка до показа ответа |
| Метод зелёной ручки | хвалим верное (mascot/lines) | в итогах: сначала «что получилось» (зелёным), потом 1 ошибка для работы |
| Контроль (assessment) | звёзды (8 вопросов) | босс-дело по теме + месячная «контрольная сыщика» с отчётом родителю по темам ФОП |
| Перенос между предметами | случайный (арифметика в окружайке) | осознанный: межпредметные задачи в math4 с пометкой |

## 5. Технические замечания, которые влияют на методику

1. **id вопроса = номер в массиве** (`uid#n`, academy.js:11, 103). Если вставить вопрос в середину или поменять порядок QUIZ_EXTRA, история «решено / ошибка» перепутается. → Стабильный id: хеш текста `qHash(q)` (уже есть для генераторов) или явное поле `id`.
2. **«Проверь себя» раскрывает ответ** в атрибуте `data-c` (coach.js:153).
3. **Новое дело → выбор тем** подменяет темы математикой (§1D).
4. Нет защиты от «межпредметной» арифметики в валидаторе (§1.3, шаг 3).
